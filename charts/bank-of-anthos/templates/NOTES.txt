Before pods become Ready you must provide:

1. ECR images (injected / bumped, not pasted into Git)
   - global.imageRegistry from Terraform → Argo Helm parameters
   - image.tag per env in values-dev.yaml / values-prod.yaml (CI / promote)

2. RDS endpoints (injected by Terraform → Argo Helm parameters at sync)
   - database.accountsDb.host / database.ledgerDb.host
     (no manual paste into values-*.yaml)

3. Kubernetes Secrets (External Secrets Operator)
   - {{ .Values.secrets.jwt.name }}
       keys: jwtRS256.key, jwtRS256.key.pub
   - {{ .Values.secrets.accountsDb.name }}
       keys: username, password, uri
       (uri = postgresql://user:pass@host:port/dbname)
   - {{ .Values.secrets.ledgerDb.name }}
       keys: username, password

4. DB schema seed (this chart)
   - dbInit.enabled={{ .Values.dbInit.enabled }}
   - Jobs: populate-accounts-db, populate-ledger-db
   - After a successful seed, set dbInit.enabled=false (or delete the Jobs)
     so ArgoCD does not keep Failed Jobs around on re-sync.
